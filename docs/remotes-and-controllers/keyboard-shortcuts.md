# Keyboard shortcuts

On iPhone and iPad, connect a keyboard and press and hold **⌘ (Command)** anywhere in Panels to see the shortcuts available on the current screen. On Mac, the same shortcuts are listed in the menu bar. The lists below are a reference for when you are mapping buttons on a remote or controller.

{/* TODO screenshot: the shortcut overlay shown when holding ⌘ in the library and in the reader (iPad, light mode) */}

Key symbols: **⌘** Command · **⇧** Shift · **⌥** Option · **⌃** Control · **⎋** Escape

## Reading

For how the arrow keys turn pages in each reader mode, see [Keys that turn pages](./how-it-works.md#keys-that-turn-pages).

| Action | Shortcut |
| --- | --- |
| Turn page (horizontal) | ⇧ ← / ⇧ → |
| Turn page (vertical) | ⇧ ↑ / ⇧ ↓ |
| Go to first page | Home |
| Go to last page | End |
| Previous / next comic | ⌃ ⌘ ← / ⌃ ⌘ → |
| Show or hide page thumbnails | ⎋ |
| Zoom in | ⇧ ⌘ + |
| Zoom out | ⇧ ⌘ - |
| Configure reader | ⌃ S |
| Switch reader preset | ⌃ 1, ⌃ 2, … (in the order of your presets) |
| Enable Panels View | ⌃ P |
| Reverse reading direction | ⌃ R |
| Enable incognito | ⌃ I |
| Live Text | ⌃ T |
| Subject detection | ⌃ ⌘ T |
| Share page | ⌃ ⌘ P |
| Save page to disk | ⌘ P |
| Reduce noise | ⌃ ⌘ 1 |
| Sharpness | ⌃ ⌘ 2 |
| Reduce moiré | ⌃ ⌘ 3 |
| Remove borders | ⌃ ⌘ 4 |

## Moving around the app

| Action | Shortcut |
| --- | --- |
| Library | ⌘ 0 or ⇧ ⌘ L |
| Reading now | ⇧ ⌘ R |
| Search | ⇧ ⌘ S |

| Previous / next tab | ⌃ ⌘ ← / ⌃ ⌘ → |
| Connect service | ⌥ ⌘ S |
